# JavaScript - DOM Manipulation

This project is a series of tasks focused on mastering Document Object Model (DOM) manipulation using JavaScript. It covers selecting elements, handling events, updating styles, managing classes, and fetching data from external APIs.

## Task 0: Color Change
A script that updates the text color of the `<header>` element to red (#FF0000) directly.
* **File:** `0-script.js`

## Task 1: Click and Turn Red
Updates the text color of the `<header>` element to red when the user clicks on the tag with ID `red_header`.
* **File:** `1-script.js`

## Task 2: Add .red Class
Adds the class `red` to the `<header>` element when the user clicks on the tag with ID `red_header`.
* **File:** `2-script.js`

## Task 3: Toggle Classes
Toggles the class of the `<header>` element between `red` and `green` when the user clicks on the tag with ID `toggle_header`.
* **File:** `3-script.js`

## Task 4: List of Elements
Adds a `<li>Item</li>` element to a list (`ul.my_list`) when the user clicks on the tag with ID `add_item`.
* **File:** `4-script.js`

## Task 5: Change the Text
Updates the text of the `<header>` element to "New Header!!!" when the user clicks on the element with ID `update_header`.
* **File:** `5-script.js`

## Task 6: Star Wars Character
Fetches a Star Wars character name from an API and displays it in the HTML tag with ID `character`.
* **URL:** `https://swapi-api.hbtn.io/api/people/5/?format=json`
* **File:** `6-script.js`

## Task 7: Star Wars Movies
Fetches and lists the titles for all Star Wars movies into a `<ul>` with ID `list_movies`.
* **URL:** `https://swapi-api.hbtn.io/api/films/?format=json`
* **File:** `7-script.js`

## Task 8: Say Hello!
Fetches a translation of "hello" based on the language and displays it in the element with ID `hello`. The script works even when imported in the `<head>` tag.
* **URL:** `https://hellosalut.stefanbohacek.com/?lang=fr`
* **File:** `8-script.js`

## Requirements
* All scripts are written in JavaScript.
* The code is tested in a browser environment.
* Vanilla JavaScript only (No JQuery).
